# Project Screenshots

Drop **4 screenshots per project** here, named `1.png` … `4.png`, inside the
folder matching each project slug:

```
public/projects/
  btn-ai/      1.png 2.png 3.png 4.png
  dcktrp/      1.png 2.png 3.png 4.png
  pegadaian/   1.png 2.png 3.png 4.png
  byd/         1.png 2.png 3.png 4.png
```

Guidelines:
- Same aspect ratio for all — they render in a locked **16:10** grid, so
  landscape captures (e.g. 1600×1000) look best.
- `.png`, `.jpg`, `.webp` all work — keep the `.png` filename or update the
  `imgs()` helper in `app/components/data.ts`.
- Until a file exists, the tile shows a labeled gradient placeholder.
